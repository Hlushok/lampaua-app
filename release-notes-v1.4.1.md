# LampaUa 1.4.1

## Нове

- Новий значок LampaUa KinoHub для ярлика, системних ТВ-категорій і банера Android TV.
  Логотипи вже створених каналів оновлюються без зміни їхніх ID.
- Додано стабільні зміни LAMPA v1.13.6 / v1.13.7.
- Just+ і Syntex отримують обмежене за розміром вікно довгого плейлиста, щоб
  уникати перевищення ліміту Android Binder. Прогрес повертається до правильних
  епізодів повного списку; пропущені епізоди не позначаються переглянутими.
- Запит «Продовжити перегляд» у Just+ з'являється лише за наявності позиції.
- Нативні HTTP-запити враховують метод GET, HEAD, POST, PUT, PATCH, DELETE, OPTIONS.
- Відновлено подію видимості сторінки після повернення з плеєра, коли з'єднання
  лишається активним. Прибрано файлові менеджери RS/TCL зі списку відеоплеєрів.

## Збережено

Наш незалежний рядок трендів / «Продовжити перегляд», профільна синхронізація
штатних ТВ-каналів і окремий протокол UA Player. Збір Google advertising ID
з upstream не додано. Вихідний Android-код і ключ підпису залишаються приватними.

Універсальний APK: arm64-v8a, armeabi-v7a, x86, x86_64. Мінімальний Android API 16.
Package `com.lampaua.app` і підпис не змінені. Встановлюйте поверх попередньої
версії, без видалення застосунку й очищення даних.

## Перевірено

63 JVM-тести, 18 перевірок вебклієнта та 158 перевірок установленого APK на Google
TV 14: оновлення з 1.4.0 зі збереженням даних, плеєрні контракти, системні картки,
точна міграція логотипів, чутливість bridge і справжній запуск каталогу KinoHub.
Lint: 0 помилок; залишаються 72 попередження.

Емулятор не замінює перевірки на фізичній Xiaomi TV Box S (3rd Gen), реального
відтворення зовнішніми плеєрами чи хмарного прогресу авторизованого користувача.
Під час запуску не завантажився сторонній `obsidian.js`, але каталог відкрився.
