# LampaUa App

LampaUa App - це Android-додаток для користувачів нашого сервера LampaUa / KinoHub.

Він відкриває KinoHub з уже підготовленими налаштуваннями, авторизацією та плагінами сервера, щоб зручно користуватися сервісом на телевізорі, приставці або Android-пристрої.

Додаток встановлюється поруч зі звичайною LAMPA. Він не переписує її, не замінює і не заважає користуватися оригінальним додатком.
