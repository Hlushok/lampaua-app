## Що змінилось

- Оновлено Android-обгортку до стабільної LAMPA `v1.13.5`, включно зі змінами `v1.13.4`.
- Виправлено збереження прогресу Just+ Player: звіти прив'язані до свого запуску й картки, а незмінений прогрес не записується повторно поверх даних з інших пристроїв.
- Покращено обробку звітів Just+ у фоні: вони застосовуються після повернення в LampaUa; періодичні звіти під час перегляду обробляються, якщо увімкнене збереження з'єднання з плеєром.
- Для Just+ додано коректну передачу режимів «спитати про продовження» та «почати спочатку», а також оновлено позначки переглянутих серій і рекомендації «Продовжити перегляд».
- Виправлено запуск Just+ для карток TMDB із зображеннями без мовної позначки.
- Виправлено закриття меню й діалогів при переході до контенту зі збереженим з'єднанням із плеєром.
- Додано API окремих каналів рекомендацій для плагінів на Android TV 8.0+. Плагін має сам підтримувати цей API та публікувати список; автоматично нові канали не з'являються.
- Збережено окремий протокол UA Player: JSON-плейлист, вибрана серія, позиція перегляду, якість, субтитри, метадані та налаштування автоматичного переходу.

Назва **LampaUa**, package `com.lampaua.app`, оформлення, стартова адреса `https://kinohub.uk/`, вибір наших серверів і вбудована перевірка оновлень залишилися без змін. Мінімальну версію Android та набір архітектур не змінено.

## Встановлення

1. Завантажте APK або скористайтеся вбудованою перевіркою оновлень у LampaUa App.
2. Встановіть його поверх попередньої версії. Видаляти додаток і його дані не потрібно.
3. Підтвердьте встановлення в системному інсталяторі Android.
